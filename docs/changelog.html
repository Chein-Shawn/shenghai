Updates that help singers practice sooner.

This changelog keeps user-facing VocalDive changes in one place: new features, interface improvements, and fixes that affect rehearsal.

7/10
July 10, 2026Score

MusicXML and Scan to MusicXML are clearer paths

  • Score work is now presented as task-based entry points instead of a research console.
  • MusicXML editing and scanned-score conversion are treated as separate workflows.
  • VocalDive continues preparing on-device OMR so scanned scores can become editable MusicXML.
7/09
July 9, 2026Support

VocalDive / 聲潛 branding and support domain

  • The public product name is now VocalDive / 聲潛.
  • Official website and support contact are aligned around www.vocaldive.com and support@vocaldive.com.
  • User-facing pages are being rewritten for singers, choir members, and early testers.
7/08
July 8, 2026Score

Twinkle sample pack for first-time testing

  • A copyright-safe Twinkle sample is available for trying score import and review.
  • The sample is intended to help new users test the flow even without a score nearby.
  • Scanned results should still be reviewed before practice.
7/06
July 6, 2026Practice

Practice tools continue expanding

  • Practice areas now include pitch-oriented rehearsal, metronome, piano reference, and tuning fork planning.
  • The goal is to help singers connect score reading, listening, and voice feedback.
6/30
June 30, 2026Support

Settings, feedback, and sync direction

  • Settings now gathers language, usage, documentation, contact, and feedback areas.
  • iCloud sync is being shaped around same-Apple-ID devices and user-controlled setup.
  • Feedback is planned as a simple path for bug reports and feature suggestions.
