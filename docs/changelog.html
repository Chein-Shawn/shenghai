聲海更新日誌

2026-06-07 Experimental

新實驗功能

  • Experimental：新增 Singing Support Lab，作為健康相關唱歌研究原型區，提供溫和哼唱、call-and-response 與舒適度紀錄，並明確標示不是醫療或治癒功能。
  • Experimental：新增唱完整首歌才解除的鬧鐘概念原型，使用 Happy Birthday 作為第一個模板，並追蹤歌曲完整度與音準比例。
  • Experimental：新增文字節奏朗讀概念原型，可把合法使用的段落轉成節奏提示，並追蹤 clarity、rate、rhythm alignment 與 completion。

2026-06-06 Public Demo

網站與 Demo

  • 新增 Happy Birthday 網頁 Demo：使用者可以播放旋律、開啟麥克風、跟唱並查看紅色/綠色音準回饋。
  • 將 Happy Birthday Demo 放到首頁主要入口，讓第一次來訪的使用者可以直接試唱。
  • 公開網站改為繁體中文/英文雙語，可由使用者手動切換語言。
  • 使用手冊與更新日誌移到網站根目錄，方便從 GitHub Pages 直接開啟。
  • 新增對外展示頁面，讓評審、mentor 或內測者能快速理解聲海概念與原型。

2026-06-06 Alpha Core

App 功能

  • 打譜功能：新增 Compose 頁面，可建立單聲部 MusicXML 草稿、加入音符/休止符、載入練習流程或匯出 MusicXML。
  • 支援頁面：可以從 App 內開啟使用手冊、更新日誌，並送出錯誤或功能建議。
  • 使用時間統計：可以查看每日使用趨勢，以及各功能花費的時間。
  • 譜面標註：加入向量筆跡標註，適合記錄換氣、音準、節奏與排練提醒。
  • 練習工具：加入節拍器、鋼琴音與標準音，幫助開始練習前建立音高和節奏基準。

樂譜與練習回饋

  • OMR 工具選擇：可以在 Score 頁選擇 homr 或 oemer 作為外部樂譜辨識流程，完成後再匯入 MusicXML。
  • 聲海現在能建立譜面目標音高時間線，讓未來的即時音準回饋更精準。
  • 加入本機或授權音檔的比對基礎，可標出音高或節奏和譜面不一致的地方。
  • 藍色標記代表參考音檔與譜面不同，等待確認；紅色代表使用者練習時唱錯。
  • 補充 Audiveris OMR 安裝與測試路線說明，保留 PDF/圖片樂譜轉 MusicXML 的研究路徑。
