# Shenghai Support Site

This folder is a static support site for GitHub Pages.

Recommended setup:

1. Push the repo to GitHub.
2. In GitHub, open `Settings -> Pages`.
3. Source: deploy from branch.
4. Branch: `main`.
5. Folder: `/docs/site` if GitHub offers that path, or move these files to `/docs` for the standard `/docs` publishing option.

Planned URL:

```text
https://chein-shawn.github.io/shenghai/
```

The app currently links to:

- `https://chein-shawn.github.io/shenghai/manual.html`
- `https://chein-shawn.github.io/shenghai/changelog.html`
