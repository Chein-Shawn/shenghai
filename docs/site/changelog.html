Shenghai Changelog

2026-06-06 Alpha

  • Added Support screen with manual, changelog, GitHub Issue, and mail draft links.
  • Added local usage tracking by feature and day.
  • Added score/audio alignment core for local or licensed audio.
  • Added blue performance-difference model and non-destructive edit proposals.
  • Added vector score annotation prototype.
  • Added metronome, piano, and tuning fork practice tools.
  • Added MusicXML target pitch timeline with basic repeat expansion.

Known Limitations

  • PDF/image OMR is not yet available inside the app.
  • YouTube MP3 downloading is intentionally not implemented.
  • Usage statistics are local-only and not yet exportable.
  • Localization strategy is documented but app strings are not fully extracted into a String Catalog yet.
