Shenghai User Manual

聲海目前是 Alpha prototype，核心目標是把樂譜變成可練習、可聽、可追蹤的聲樂/合唱訓練工作台。

1. Import Score

  1. Open the app and go to Score.
  2. Use MusicXML import first. PDF/image score recognition is still an OMR research path.
  3. After import, select the voice part you want to practice.

2. Playback And Export

  1. Use playback to hear the selected part.
  2. Export MIDI when you need an intermediate audio proof.
  3. Future versions will add richer sampler sounds and local audio comparison.

3. Practice

  1. Go to Practice.
  2. Use metronome, piano, and tuning fork tools to prepare pitch and rhythm.
  3. Live microphone pitch tracking is experimental and should be treated as feedback, not diagnosis.

4. Score Annotation

Score annotation uses vector strokes, so zooming should preserve clear lines better than pixel-only drawing. Export and persistence are planned for future builds.

5. Score / Audio Alignment

Current safe design: compare MusicXML against local audio, user recordings, or licensed rehearsal tracks. YouTube links can be used as reference metadata, but the app should not download YouTube videos as MP3.

6. Feedback

  1. Go to Support.
  2. Choose Bug, Feature, Usability, or Research.
  3. Use GitHub Issue for invited internal testers, or Mail Draft as fallback.

7. Usage Stats

Go to Usage to inspect local usage time by day and by feature. The current version stores this locally through UserDefaults.
