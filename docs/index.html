一個工作區，從讀譜到演唱

樂譜是起點，不是排練的終點。

VocalDive 把看譜、修譜、分部與回饋串起來，讓你把時間留給真正的音樂。

01 / SCORE IN

匯入樂譜

使用 PDF、圖片或 MusicXML，讓練習從你手上的版本開始。

02 / SHAPE

編修 MusicXML

在視覺化樂譜中整理音符、聲部與結構，讓資料真的適合你的排練。

03 / PART WORK

練習自己的聲部

聚焦 S、A、T 或 B，聽見旋律在合唱裡的位置。

04 / PITCH

看見音準

用視覺回饋觀察演唱與樂譜的關係，知道下一次要怎麼調整。

05 / MARK

保留你的註記

手寫提示、換氣和排練想法仍留在原始頁面旁，不會被排版樂譜取代。

06 / RETURN

回到你的進度

記住上次工作的樂譜與流程，讓每一次練習都接得上。
