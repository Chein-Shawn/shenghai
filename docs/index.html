為聲樂與合唱練習打造的智慧練習工作台

聲海像是聲樂界的 Strava：把樂譜、聲部練習、音準回饋、練習時間與聲音狀態放在同一個地方，幫助歌者更科學地練習、追蹤進步。

聲海能幫你做什麼

匯入樂譜

以 MusicXML 作為第一版主要格式，把樂譜轉成可播放、可分析、可練習的資料。

自己打譜

在 App 內建立單聲部旋律，加入音符與休止符，匯出 MusicXML 或直接載入練習流程。

選擇聲部練習

合唱團員可以專注自己的聲部，也能搭配播放與節拍工具練習進入點。

音準與節奏回饋

透過目標音高時間線與麥克風追蹤，逐步建立唱準、唱穩、回顧錯誤的能力。

清楚標註譜面

使用向量筆跡標註譜面，放大時仍保持清晰，適合記錄呼吸、換氣、咬字與指揮提醒。

練習工具

內建節拍器、鋼琴音、標準音，讓你在練聲部前快速建立音高與節奏中心。

練習時間統計

查看每日使用趨勢與各功能使用時間，幫助你知道自己是否穩定練習。

新手使用流程

匯入、載入或自己打譜先使用 MusicXML，也可以在 Compose 建立簡單旋律；之後版本會逐步強化 PDF/圖片樂譜辨識。
選擇要練的聲部例如 Soprano、Alto、Tenor、Bass，或你的獨唱旋律線。
播放、標註、練習用播放、節拍器、鋼琴與標準音建立練習基準，再把提醒寫在譜上。
追蹤表現與回饋查看音準偏差、練習時間與待修正處，讓下一次練習更有效。

目前適合誰

合唱團員

快速過譜、熟悉聲部、記錄排練提醒。

聲樂初學者

建立音準意識，追蹤每天練習習慣。

音樂學習者

把視唱、音程、譜面標註與聲音回顧放在同一個工作流。
