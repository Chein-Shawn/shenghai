聲海使用手冊

這份手冊給第一次使用聲海的歌者、合唱團員與內測者。你不需要懂工程或演算法，只要照著流程，就能開始把樂譜變成可練習、可追蹤的聲音訓練。

第一步：掃描、校正或建立樂譜

自己打譜：Compose

  1. 進入 Compose。
  2. 設定標題、聲部名稱、速度與拍號。
  3. 選擇音名、升降記號、八度與時值，加入音符或休止符。
  4. 選擇 Load Score 載入 Score 與 Practice；或選擇 Export MusicXML 產生可分享檔案。

第一版 Compose 適合建立單聲部旋律、聲部練習線與簡單校正稿；完整多聲部排版與專業製譜功能會在後續版本擴充。

主要格式：可校正的 MusicXML

  1. 打開 App，進入 Score。
  2. 從 PDF/圖片辨識出的 MusicXML、自己打譜產生的 MusicXML，或既有 MusicXML 檔案開始。
  3. 在 Full-Score MusicXML Review 檢查標題、聲部、小節、音符、休止符、歌詞、力度、速度文字、反覆記號與版面。
  4. 修正 MusicXML 後，再用同一份檔案進行標註、播放、音準回饋與練習紀錄。

聲海的主流程是先把樂譜變成可校正 MusicXML，再讓使用者確認掃描結果。OMR 可能出錯，所以校正門檻是正式練習前的必要步驟。

PDF/圖片樂譜：辨識成完整 MusicXML 候選稿

  1. 進入 Score 的 OMR Review 區塊。
  2. 選擇 homr 或 oemer。
  3. 依照 App 顯示的外部流程提示，將 PDF/圖片轉成 MusicXML 候選稿。
  4. 匯入候選稿後，使用 Full-Score MusicXML Review 檢查所有頁面資訊。
  5. 校正錯誤後，再進入聲部練習、譜面標註、播放驗證與音準追蹤。

目標不是只辨識音符，而是盡量把 PDF/圖片上的標題、聲部、音符、休止符、歌詞、力度、速度文字、反覆記號與版面資訊都轉成可編輯 MusicXML。

第二步：選擇聲部

讓練習聚焦在你要唱的線條

  1. 在 Score 頁面選擇你的聲部或旋律線。
  2. 用播放功能聽目標音高與節奏。
  3. 反覆確認容易進錯、容易偏音或需要換氣的段落。

第三步：使用練習工具

建立音高與節奏基準

  • Metronome：練習速度穩定、切分與進入點。
  • Piano：快速確認目標音、音程與聲部起音。
  • Tuning Fork：建立標準音中心，避免一開始就唱偏。
  • Live Pitch：用麥克風追蹤音高，協助你理解自己偏高或偏低。

Live Pitch 是練習回饋，不是醫療或聲帶診斷。請把它當成幫你看見練習趨勢的工具。

第四步：標註、修正、追蹤

把排練提醒留在樂譜上

  • 標記換氣、子音、母音、重音、漸強漸弱、指揮提醒。
  • 紅色代表練習時你唱出的音與譜面目標不一致。
  • 藍色代表參考音檔或錄音和譜面不一致，等待你確認是否修改。

第五步：查看使用時間並回報問題

把練習變成可追蹤的習慣

  1. 進入 Settings 查看每日使用趨勢與各功能時間。
  2. 進入 Settings 的 Feedback 區塊，直接在 App 內回報 Bug、功能建議、易用性問題或研究想法。
  3. 你可以在 Settings 的 Sync 區塊選擇是否啟用 iCloud，同步樂譜、註記、使用紀錄、顯示語言與訓練資料到同一 Apple ID 的裝置。

回饋送出時，會附上 app 版本、平台、目前頁面與顯示語言，方便開發者重現問題；練習資料與樂譜不會因為這個回饋表單而自動上傳。

實驗功能

尚在測試中的有趣功能

Experimental 區域目前聚焦在概念驗證與互動原型，保留較有實驗性的功能，方便你先試用、再決定是否納入日常練習流程。

實驗功能：唱完整首歌才解除的鬧鐘

把起床變成一個完整歌曲挑戰

  1. 設定起床時間與歌曲模板，目前第一個模板是 Happy Birthday。
  2. 收到系統提醒後，開啟聲海並開始唱歌挑戰。
  3. 聲海會追蹤你唱到多少目標音，以及音準接近度是否達標。
  4. 只有當完整度與音準比例達標時，App 內的鬧鐘狀態才會標記為解除。

這不是生命安全、服藥或緊急提醒用鬧鐘。iOS/macOS 不能保證 App 在關閉、鎖屏、靜音、Focus、通知被關閉或裝置關機時仍能強制持續響鈴或錄音；真正的唱歌判定會在你開啟聲海後執行。

實驗功能：文字節奏朗讀

把段落變成有節奏的朗讀或吟唱練習

  1. 匯入你自己寫的、公共領域、已授權或可合法使用的文字。
  2. 選擇分類與段落內容；段落可以是英文、中文，或中英混合。
  3. 聲海會用標點與換行把段落切成 phrase，並依語言模式產生節奏提示。
  4. 英文 phrase 會保留字級節奏提示；中文與混合 phrase 以 phrase 為主要評分單位。
  5. 完成後查看 clarity、rate、rhythm alignment、phrase match、completion，再關掉節奏提示重測。

這是練習與追蹤工具，不是治癒、診斷、醫療器材或語言治療替代品。v1 的 phrase 邊界來自標點與換行。請不要匯入未授權的文章、書籍、歌詞、新聞或詩。

聲海仍在 Alpha 內測階段。這份手冊會隨 App 功能持續更新。
