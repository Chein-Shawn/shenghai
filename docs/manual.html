聲海使用手冊

這份手冊給第一次使用聲海的歌者、合唱團員與內測者。你不需要懂工程或演算法，只要照著流程，就能開始把樂譜變成可練習、可追蹤的聲音訓練。

第一步：建立或載入樂譜

自己打譜：Compose

  1. 進入 Compose。
  2. 設定標題、聲部名稱、速度與拍號。
  3. 選擇音名、升降記號、八度與時值，加入音符或休止符。
  4. 選擇 Load Score 載入 Score 與 Practice；或選擇 Export MusicXML 產生可分享檔案。

第一版 Compose 適合建立單聲部旋律、聲部練習線與簡單校正稿；完整多聲部排版與專業製譜功能會在後續版本擴充。

目前建議格式：MusicXML

  1. 打開 App，進入 Score。
  2. 載入示範樂譜，或匯入自己的 MusicXML 檔案。
  3. 確認樂譜標題、聲部、小節與音符數量是否合理。

如果你手上是 PDF 或圖片樂譜，之後版本會逐步支援辨識。現階段可以先用 MuseScore、掃譜工具或其他 OMR 工具轉成 MusicXML。

PDF/圖片樂譜：選擇 homr 或 oemer

  1. 進入 Score 的 OMR Review 區塊。
  2. 選擇 homr 或 oemer。
  3. 依照 App 顯示的外部流程提示，將樂譜圖片轉成 MusicXML。
  4. 把產生的 MusicXML 匯入聲海，繼續做聲部練習與播放驗證。

homr/oemer 目前不是直接在 App 內執行；它們是外部辨識流程選項。這樣可以先測辨識品質，同時避免要求所有使用者安裝研究工具。

第二步：選擇聲部

讓練習聚焦在你要唱的線條

  1. 在 Score 頁面選擇你的聲部或旋律線。
  2. 用播放功能聽目標音高與節奏。
  3. 反覆確認容易進錯、容易偏音或需要換氣的段落。

第三步：使用練習工具

建立音高與節奏基準

  • Metronome：練習速度穩定、切分與進入點。
  • Piano：快速確認目標音、音程與聲部起音。
  • Tuning Fork：建立標準音中心，避免一開始就唱偏。
  • Live Pitch：用麥克風追蹤音高，協助你理解自己偏高或偏低。

Live Pitch 是練習回饋，不是醫療或聲帶診斷。請把它當成幫你看見練習趨勢的工具。

第四步：標註、修正、追蹤

把排練提醒留在樂譜上

  • 標記換氣、子音、母音、重音、漸強漸弱、指揮提醒。
  • 紅色代表練習時你唱出的音與譜面目標不一致。
  • 藍色代表參考音檔或錄音和譜面不一致，等待你確認是否修改。

第五步：查看使用時間並回報問題

把練習變成可追蹤的習慣

  1. 進入 Usage 查看每日使用趨勢與各功能時間。
  2. 進入 Support 回報 Bug、功能建議、易用性問題或研究想法。
  3. 目前使用資料儲存在本機，不會自動上傳。
聲海仍在 Alpha 內測階段。這份手冊會隨 App 功能持續更新。
